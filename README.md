# Zig Control Panel

A convenience GUI program written in Zig 

## 💻 Tech Stack

**Programming Language** - [Zig](https://ziglang.org/)  
**UI Layout Library** - [Zig port of Clay C UI library](https://github.com/johan0A/clay-zig-bindings)  
**UI Renderer** - [Zig port of raylib - used by Clay](https://github.com/Not-Nik/raylib-zig)
